## 先说清楚:不是浏览器,不是浏览器,不是浏览器!

重要的事情说三遍。整个界面是**纯 Direct2D / GDI+ 逐帧自绘**的——不是套壳、不是 Electron、不挂任何浏览器内核。你看到的每一个像素,都是一笔一笔画出来的,所以它轻、快、省内存。

![主界面 + AI 助手](视频封面.png)

它是干嘛的:Windows 全盘文件搜索工具,定位和 Everything 类似,但走得更远——

- **六种搜索姿势随便切**:拼音(全拼/首字母)、通配符(`*` `?`)、正则表达式、SQL、Lua 过滤、Lua 执行;
- **AI 助手**:接上任意 OpenAI 兼容接口的大模型(DeepSeek、本地部署模型都行)直接对话。它自己会调搜索、读文件、复制移动、跑命令——**配合 AI,只有硬盘上不存在的,没有找不到的**;
- **多窗口,一窗一世界**:Ctrl+N 随便开,每个窗口都是完全独立的一套——皮肤、界面语言、搜索模式、排序、快捷键、窗口行为全都各配各的。可以一个窗口英文极简风专门挂 SQL 查询,另一个中文皮肤窗日常找片;再配上**全局双击 Ctrl 随时唤起**,任何界面秒出搜索框,找东西再也不用点开始菜单看它转圈——基本就是"替代 Windows 默认搜索"的用法;
- **空间地图**:整盘空间占用一屏看穿,哪个文件夹吃掉几百 GB 一目了然;
- 其他:图片/文本预览、文件别名与评分、列自定义、六国界面语言、原生插件系统……

**说好的"不是浏览器",怎么又冒出个 WebView2?**

交代清楚:主程序——搜索窗、列表、设置、预览——至今仍是纯 D2D/GDI+ 自绘,一个系统控件都没用。唯一用到 WebView2(系统自带的 Edge 内核组件,Win10/11 出厂就有,不额外打包、不占安装体积)的地方,是 **AI 助手的聊天面板**。原因很简单:AI 吐出来的内容不可控——Markdown、表格、代码块、图片混着来,最早尝试过纯 GDI+ 手写渲染,排版效果和开发成本都不理想。于是聊天这一块交给成熟的 HTML 渲染,主程序依旧一笔一笔画,各干各擅长的。

**和 Everything 对比(优缺点都摆出来)**

先说句公道话:Everything 是这个领域的标杆,2004 年做到现在,免费、稳定、快。蜗牛快搜是 2026 年的新兵,下面把两边的长短都摊开说:

| | 蜗牛快搜 | Everything |
| --- | :---: | :---: |
| 拼音搜索(全拼/首拼) | ✅ 与通配符随意混合 | ✅ 1.5 支持(拼音/首拼,二选一) |
| AI 助手(对话式找文件) | ✅ | ❌ |
| 空间地图(整盘占用总览) | ✅ | ❌ |
| SQL / Lua 查询 | ✅ | ❌ |
| 正则表达式 | ✅ | ✅ |
| 文件预览(图片/文本) | ✅ 内置 | ✅ 1.5 支持 |
| 界面语言 | 6 种 | ✅ 数十种 |
| 远程访问(HTTP 服务器) | ❌ 暂无 | ✅ |
| 命令行工具 | ❌ 暂无 | ✅ es.exe |
| 内存占用(443 万文件同口径实测) | **约 307 MB** | 约 417 MB |
| 发行包体积 | 约 5 MB(含 AI 插件) | ✅ 约 2 MB |
| 源码 | 开源 | 闭源(免费) |
| 成熟度 | 新项目 | ✅ 20 年沉淀 |

**Everything 更强的地方(蜗牛快搜的缺点,先认)**:成熟度(20 年打磨对新项目,极端场景、兼容性、长期稳定性不在一个量级,这个得认);极致轻量(便携版 2MB 上下,蜗牛全功能发行包约 5MB——都不大,但它更小,老机器上更省心);首次建索引(NTFS 直读方案深耕多年,建库速度公认强项);远程访问(自带 HTTP/FTP 服务器,别的设备开浏览器就能查);命令行生态(es.exe 配合脚本很顺手);语言覆盖(界面语言数十种,蜗牛目前 6 种)。

**蜗牛快搜多出来的几块**:拼音混搜(全拼/首拼/通配符随意混合,Everything 1.5 是二选一);AI 助手(自然语言对话找文件,自己会调搜索、读文件、批量改名/复制/移动);空间地图(整盘占用一屏看穿);SQL / Lua 查询(复杂条件、批量处理一把梭);内存实测更低(443 万文件同口径 307 MB vs 417 MB,低约 26%);单进程多搜索窗口 + 全局唤起(Ctrl+N 开多少个都行,每窗独立皮肤/界面语言/搜索设置/快捷键,双击 Ctrl 任何界面秒唤搜索框,可当启动器替代 Windows 默认搜索);功能面(内置图片/文本预览、文件别名与评分、皮肤主题、原生插件系统);开源可审(成品层源码全在仓库里)。

一句话:要极致轻量、成熟稳定、远程访问和脚本生态,Everything 依旧是首选,不亏;要拼音混搜、AI、空间总览、SQL/Lua,可以试试蜗牛快搜。俩都免费,装一起也不冲突。

**四不问**

一、不要问"会不会偷数据"?开源的,代码全在那儿摆着。(何况你的代码可能还没 AI 写得好,偷来干啥)

二、不要问"会不会联网、上传数据"?不开 AI 助手、空间地图(评估面板)这类功能,程序不会有任何联网行为。

三、不要问技术细节?本程序是用 AI 写的,技术问题下载源码后直接问 AI,它比我清楚得多。你问我,我还要去问 AI 再来回答你,白白浪费 token。

四、不要问"AI 会不会上传我的文件内容"?默认不会,只允许上传文件路径、大小、修改时间等基本信息。实在介意,接本地部署的模型,一个字节都不出门。(也可以下载源码问 AI 它会不会偷。)
