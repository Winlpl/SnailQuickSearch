插件

搜索引擎之外,
还是一台可编程机器

插件 = manifest.json + 原生 DLL 双件式。 纯声明式插件(菜单、搜索模式)不用写一行代码; 动态能力用纯 C ABI 的 SDK 开发,C/C++ 即可上手。

应用菜单搜索模式文件右键 搜索框右键预览接管状态栏挂件 事件订阅批量重命名
file.read file.write exec ui

权限四档,声明在清单、宿主边界强制、管理页可审计;新插件默认禁用,首次启用需你亲自确认。

 plugins/<插件id>/
# 一个插件,一个目录
├─ manifest.json   # 能力声明(中文主键)
│    · 菜单项 / 搜索模式 → 纯声明,零代码
│    · 权限声明:file.read / write / exec / ui
└─ <插件>.dll      # 动态能力(可缺省)
     · 纯 C ABI SDK,头文件一个
     · 扩展点:菜单 / 预览 / 状态栏 / 事件…
